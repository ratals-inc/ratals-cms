# Security Policy

## Reporting a Vulnerability

We take the security of Ratals seriously. If you discover a security vulnerability within the core or business modules, please do **not** open a public issue. Instead, please email us directly.

* **Email:** support@ratals.com
* **Response Time:** We aim to acknowledge all reports within 48 hours.

## Supported Versions

Currently, only the latest release of Ratals Core is supported with security updates. We recommend always running the most recent version provided via the internal "One-Click" update system.
