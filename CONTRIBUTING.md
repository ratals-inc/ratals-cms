# Contributing to Ratals

First off, thank you for considering contributing to Ratals! It’s people like you that make the open-source community great.

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the core, please open a GitHub Issue. Provide as much detail as possible, including your PHP version and web server type.

### Pull Requests
We welcome pull requests for the **Ratals Core (Apache 2.0)**. 
1. Fork the repo.
2. Create your feature branch.
3. Submit a PR with a clear description of the changes.

*Note: We do not accept public contributions for proprietary Business Modules (Commerce, ERP, AI). For those, please contact our dev team via support@ratals.com.*

## Code of Conduct
By participating in this project, you agree to abide by our standards of professional and respectful communication.
